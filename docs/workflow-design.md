# 原生工作台流程设计

目标：先创建工程、配置并保存，然后进入编辑。一首歌只维护一个工作区，之后不再为了试听、
校准、保存或输出，在制作页、歌词编辑器和结果页之间手动交接工程。项目配置不占据常驻编辑区。

## 官方产品流程对比

以下根据 2026-09-30 查阅的官方页面与手册整理，未安装或实测这些第三方产品。
“借鉴”列是本项目的设计判断，不意味着各产品实现完全相同。

| 产品 | 官方描述的流程 | 本项目借鉴 |
| --- | --- | --- |
| Karaoke Builder Studio | 随音乐按空格同步、减速与回退；独立精修窗口把词级时间条与屏幕预览放在一起；同步后可直接构建。 | 初步制作和深度精修可以分层；精修时预览跟着时间轴。 |
| AI Karaoke Video Creator | 起步可以使用向导；编辑器在同一工程中结合歌词、波形标签与预览，之后设置样式并导出。 | 起步短，工程连续；不把每个处理阶段都变成主导航页。 |
| Kanto Syncro | 主界面导入音频和文本、开始同步、撤销、变速与预览，Finish & Save 才进入输出窗口。 | 素材只导入一次；校准、试听留在原位，统一导出入口。 |
| KaraokeClip | 上传、可选转写纠正、编辑器；提供准确歌词时跳过转写纠正，编辑器内调整时间、样式、翻译并导出。 | 根据已提供的素材跳过不必要步骤；本项目继续使用本地原生处理。 |

2026-10-01 进一步查阅了工程配置与布局分工：

- [Karaoke Builder Project Settings](https://karaokebuilder.com/kbstudio.php?pg=5) 将整首歌的行距、边距和片头片尾归于项目设置。
- [Aegisub Script Properties](https://aegisub.org/docs/latest/properties/) 从文件菜单访问脚本属性，设置整份脚本的分辨率和换行等属性。
- [Subtitle Edit Main Window](https://subtitleedit.github.io/subtitleedit/features/main-window.html) 支持字幕列表、预览与音频区的多种布局，并用分隔条分配空间；[文本导入](https://subtitleedit.github.io/subtitleedit/features/import-plain-text.html) 在导入窗口收集文本与初始时间设置。

据此采用的设计是本项目的判断：创建时收集素材和初始处理配置，配置随工程保存；编辑时保留
预览、歌词与时间调整，项目设置通过独立入口修改。这些工具并非都使用同一套创建向导。

## 在 Karaoke Forge 中的实现约束

- 创建向导收集素材与项目设置；编辑工作台显示工程摘要和固定的保存/项目设置/导出入口。
- 自动准备完成后，在现有工作台载入歌词；渲染结果内联展示，不改变编辑位置。
- 不再要求用户点击“交给制作页”。每次保存、渲染时从编辑器读取并验证最新草稿。
- 切换工程才恢复其他工程的素材与配置；当前工程的歌词快照不得覆盖用户刚改的样式。
- 保存保留撤销历史，错误草稿不得作为成功版本输出，未保存修改仍有离开保护。
- 处理期间锁定相关输入以保持任务快照一致，界面继续处理窗口、日志和状态事件。
- 低频工具和环境设置独立存在，日常制作无需经过它们。

## 新建工程与校准交互

“新建工程”（Ctrl+N）按“素材来源 → 处理与外观 → 确认保存”配置。素材阶段填写工程名和
保存目录，选择歌词来源，再按选择显示本地文件、粘贴正文或在线链接字段。网易云来源同时
提供本地音频/有声 MV 与在线获取音频的选择。处理与外观阶段配置识别语言、模型、逐词精修、
音频偏移、字体、画面和输出等参数；高级选项仍保留，使用默认值也可以继续。

确认创建时先保存工程和配置，再进入编辑。尚未生成时间轴的工程可以关闭后重新打开，继续
使用保存的素材来源与处理选项。点击“生成时间轴”才读取歌词、运行 AI 或获取在线歌曲；
打开向导不会登录或请求在线内容。账号连接属于会话设置，通过“网易云账号”菜单访问。

编辑区不常驻歌曲路径、歌词链接、处理参数和成片样式表单。顶部显示项目摘要，通过
“项目设置”重新进入配置向导。当前工程使用保存按钮或 Ctrl+S 保存到原目录；需要副本时用
“工程另存为”。配置修改会保留当前歌词，重新生成时才替换；取消设置不改变工程。

取消新建不改变当前工程。确认新建后才检查未保存修改；已有任务进行中时不切换工程。
新工程清除上一首歌的素材、歌词和渲染快照，恢复自动逐字精修，并保留通用样式、识别选择和
会话登录状态。更改当前来源则保留编辑中的歌词，直到用户明确重新载入；来源未载入前不把
旧歌词当成新来源导出。

空格用于播放/暂停。在歌词、链接、名称、数值和表格单元格编辑时，空格仍属于正常输入；
按住空格不会反复切换播放状态。成品预览区域的空格控制成品播放器。播放时用平滑的视觉
播放头显示位置，实际音频位置仍由媒体播放器决定；定位和拖动时暂停自动跟随和选句，避免
界面抢走正在操作的时间轴。

编辑区使用可调整的分隔条分配歌词列表、预览和时间调整区域；“当前句逐词 / 整曲时间轴 /
更多调整”在同一区域切换，避免将所有面板垂直堆叠。切换歌词句子保留当前编辑视图。

选中一句后，逐词时间轴直接显示。点击词块选词，拖边缘独立改变词首/词尾，拖中间整体移动
该词并保持时长；相邻词不自动跟着改变。独立模式保留顺序和至少 10 毫秒时长，允许留出真实
停顿。需要共同移动相接边界时，明确开启联动选项。同一位置的共享边界优先调整已选词，也
可以用词首、词尾、整体移动的步长按钮精确微调。

时间轴刻度和空白区域可按住连续拖动播放头。吸附同时受像素距离和 80 毫秒时间距离限制，
不会因长歌曲缩小显示而跳过几秒；拖动开始后固定当前吸附参考，避免追逐移动中的播放头。
Ctrl+滚轮缩放、逐词倍率和滚动帮助选中密集短词。一次拖动在释放时只形成一次修改，Escape
取消；撤销不会按鼠标每一帧产生几十条记录。
