# 对齐算法

Karaoke Forge 使用“识别定位 + 正式歌词回填”，而不是把语音识别结果直接导出。

1. `faster-whisper` 从歌曲或分离后的人声中生成带开始/结束时间的识别词。
2. 正式歌词和识别词使用相同规则规范化：
   - Unicode NFKC 归一化；
   - 英文等空格语言按单词切分；
   - 中日韩文字按字符切分；
   - 标点保留在显示文本中，但不参与匹配。
3. 全局动态规划按顺序匹配两组词元。完全相同的词权重最高，模糊相似词次之，插入和缺失词使用间隙惩罚。
4. 已匹配词直接采用 ASR 时间；未匹配词在相邻锚点之间插值。
5. 最后按原始歌词行重新组合，生成行级和词级时间轴。

这个方案的主要优点是拼写、标点、大小写和歌词版本由用户控制。其限制也很明确：

- Whisper 的词级时间戳并非音素级强制对齐；
- 歌声、和声、混响和密集伴奏会降低识别质量；
- 大段漏唱或歌词版本不一致会让插值区间变长；
- 中日韩语言目前是字符级高亮，并不自动按语义词或音节合并。

JSON 是信息最完整的中间格式。计划中的高精度后端可以复用同一数据模型，不需要改变其他导出器和视频渲染代码。
